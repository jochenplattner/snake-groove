> Статус: CLOSED / HISTORICAL
>
> Назначение файла: сохранить результат стартовой фазы, а не описывать текущую очередь работ.

Актуальный статус проекта находится в [snake_phase_1_in_progress.md](./snake_phase_1_in_progress.md), действующая архитектура - в [SNAKE_ARCHITECTURE.md](./SNAKE_ARCHITECTURE.md).

## 1. Цель Фазы 0

Подготовить технический каркас Snake Groove до начала реализации игровых правил:

- создать Git-репозиторий;
- создать и упорядочить Unity-проект;
- настроить сцены и базовый переход между ними;
- подготовить папки для кода, графики, звука и prefab;
- определить границу между Unity и pure C# ядром;
- зафиксировать архитектурные решения в документации.

## 2. Что было создано

### Репозиторий

```text
snake-groove/
  SnakeGroove/        # Unity-проект
  INFOS/              # архитектура и планы
  .gitattributes
  .gitignore
  LICENSE
  README.md
```

- репозиторий размещён на GitHub;
- используется лицензия MIT;
- Git LFS подготовлен для бинарных ассетов;
- Unity-generated папки исключены через `.gitignore`.

### Unity-проект

Были подготовлены основные каталоги:

```text
SnakeGroove/Assets/
  Art/
  Audio/
  Prefabs/
  Scenes/
  Scripts/
    Infrastructure/
    Gameplay/
    UI/
  Settings/
  Tests/
```

Созданы сцены:

- `Boot.unity` - точка входа;
- `MainMenu.unity` - главное меню;
- `Game.unity` - будущая игровая сцена.

Созданы базовые Unity-компоненты:

- `GameManager.cs`;
- `EventBus.cs`;
- `BootLoader.cs`.

### Архитектурная основа

На границе Фазы 0 было принято решение:

- игровые правила будут вынесены из Unity;
- Unity будет отвечать за сцены, ввод, таймер, отображение и звук;
- связь с ядром будет проходить через узкий Unity-адаптер;
- ядро будет оформлено как embedded package.

Текущее имя пакета:

```text
com.jochen.snakegroovecore
```

> Историческое имя `com.jochen.snakecore` больше не используется. После рефакторинга пакет находится в `SnakeGroove/Packages/com.jochen.snakegroovecore`.

## 3. Что ещё не было готово в конце Фазы 0

В момент закрытия Фазы 0 ещё не существовало законченной игры:

- правила Snake не были полностью реализованы;
- `SnakeRunner` не связывал Unity с ядром;
- сцена `Game` не показывала змейку и еду;
- core-тесты и GitHub Actions ещё не были настроены;
- музыкальная механика не была начата;
- сборки и деплой платформ не были автоматизированы;
- Unity to Codex MCP не был подключён.

Эти пункты относятся к следующим фазам и не должны записываться как достижения Фазы 0.

## 4. Что изменилось после Фазы 0

Уже в Фазе 1 были выполнены:

- профессиональный рефакторинг pure C# ядра;
- публичный API `GameSession`, `GameSessionFactory`, `GameTickResult`, `GameSnapshot`;
- package tests;
- standalone .NET 8 test project;
- 8 core-тестов;
- зелёный GitHub Actions workflow `Core Tests`;
- настроенный и проверенный Unity to Codex MCP.

Следующие задачи Фазы 1:

1. `SnakeRunner`;
2. визуализация змейки и еды;
3. Unity integration tests;
4. закрытие Classic Snake MVP.

## 5. Версии и исторические оговорки

Текущий файл Unity-проекта фиксирует Editor `6000.3.7f1`. Старые упоминания «Unity 6.2» рядом с этим номером были противоречивы и удалены.

Standalone core-тесты используют .NET 8. Версия установленной IDE или более нового SDK не является архитектурным требованием проекта и поэтому здесь не фиксируется.

## 6. Результат Фазы 0

Фаза 0 дала проекту репозиторий, Unity-каркас, сцены, базовую инфраструктуру и направление архитектуры. Она считается завершённой. Все текущие решения и задачи ведутся в документах Фазы 1.
